      Chats

      Chats pi has had at the terminal in this directory. Promote one to make a notebook of it — a prompt cell for each message you sent, a bash cell for each command you ran — with a record of what it did. Promote leaves pi's session file as it is. Delete removes that file; a notebook already made from the chat is kept.

            Modes

            A mode is a system prompt, an optional model, and which tools and skills the agent is given. code, work, and bare come with octo and stay as they are. bare sends a prompt cell with no system prompt. A mode you add here is saved for your user and appears in the mode menu on each notebook. Leave tools or skills unnamed and the agent keeps pi's own. Naming either is a smaller set for the task, not a limit on what the account can do. Saving rewrites that mode's file.

              Models

              Pi's model settings for this user. Search for a model and set it as the default. Show configured lists only models whose provider already has a stored key, and models from custom providers you added. Show all brings the full list back. Test, beside a configured model, asks it for one token. The line that appears stays short; click it to read the full answer. Set Default makes that model the one new Runs use. A model whose provider has a key also has a switch, which includes or leaves it out of the model lists. Use the button beside each model to set, change, or reset its provider's API key. A notebook or a cell that names its own model still uses that.

                Custom providers

                Click a name, such as Oracle1, to show its settings. Each model has a context window. It starts at 200,000 tokens; change the number to give that model another size. For an OpenAI-compatible proxy, choose openai-completions and a base URL that ends at /v1. Pi adds /chat/completions itself. The Google API wants the version root, such as …/v1beta, not a chat completions path.
